SCAMSHIELD – AI-POWERED SCAM DETECTION

 1. Abstract

ScamShield is an AI-powered application that detects potentially fraudulent **URLs and suspicious messages**. It identifies social-engineering techniques such as **trust building, fear creation, urgency pressure, and authority impersonation**. Based on these factors, it generates a **risk score out of 100** and classifies the content as Low, Medium, or High Risk.

 2. Problem Statement

Scammers often manipulate users by creating **trust, fear, or urgency** and pretending to be banks, government organizations, or other trusted authorities. Users may click malicious links or share sensitive information without recognizing the scam.

 3. Proposed Solution

ScamShield allows users to enter an **unknown message or URL**. The AI analyzes the content and provides:

* Risk score
* Risk level
* Detected scam indicators
* Safety recommendation

 4. Detection Criteria

| Criteria                    | What it detects                                  |
| --------------------------- | ------------------------------------------------ |
| **Trust Building**          | Attempts to make the user trust the sender       |
| **Fear Creation**           | Threats or fear about account/money loss         |
| **Urgency Pressure**        | Forces immediate action                          |
| **Authority Impersonation** | Pretends to be a bank, government, company, etc. |

 5. Risk Score

| Score      | Risk           |
| ---------- | -------------- |
| **0–29**   | 🟢 Low Risk    |
| **30–69**  | 🟡 Medium Risk |
| **70–100** | 🔴 High Risk   |

**Example:**
**50/100 → Medium Risk**

The system may explain that the message contains moderate urgency and fear indicators, so the user should verify it before taking action.

 6. QR Code Analysis

ScamShield can also scan a **QR code**, extract the URL, and send it for the same risk analysis.

**QR → URL Extraction → AI Analysis → Risk Score → Safety Recommendation**

7. Key Features

* 🔗 URL scanning
* 💬 Suspicious message analysis
* 📱 QR code analysis
* 🤖 AI-based detection
* 📊 Risk score out of 100
* ⚠️ Safety recommendations

 8. Conclusion

ScamShield helps users identify potentially risky digital content by analyzing both **technical URL characteristics and social-engineering techniques**. It acts as an early warning system to help users think before clicking, responding, or sharing sensitive information.
